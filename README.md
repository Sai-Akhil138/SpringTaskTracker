📌 Task Tracker (Spring Boot + MVC + Thymeleaf + H2)

A simple Task Tracker web application built with Java, Spring Boot, MVC architecture, Thymeleaf, and H2 Database.
This app allows you to add, update, delete, and track tasks, with statuses like Not Started, In Progress, and Done.

🚀 Features

✅ Add new tasks
✅ Edit/update tasks
✅ Delete tasks
✅ Mark tasks as Not Started / In Progress / Done
✅ View all tasks in a simple Bootstrap-powered UI
✅ Data stored in H2 in-memory database

🏗️ Tech Stack

Java 17+
Spring Boot (Web, Thymeleaf, Spring Data JPA)
H2 Database (in-memory)
Bootstrap 5 (UI styling)
Maven (build tool)
